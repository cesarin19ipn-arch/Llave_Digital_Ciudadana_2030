# Llave Digital Ciudadana 2030 — Etapa 1

Primera versión de la interfaz, con identidad visual inspirada en las paletas de color de la Guía de Identidad Gráfica UNRC 2024–2030 (página 26). Es un **prototipo académico independiente**, no un sitio oficial.

## Revisar

1. Abre `index.html` para ver la página principal.
2. Prueba el buscador de los tres trámites y el selector de modalidad.
3. Abre `datos.xml` para ver la representación con CSS.
4. Si quieres probar el visualizador `xml.html`, selecciona manualmente `datos.xml`.

## Archivos

- `index.html`: inicio, catálogo, preguntas, consejos, arquitectura y fuentes.
- `css/estilos.css`: nueva identidad verde, guinda y dorada; diseño responsivo.
- `js/app.js`: buscador y filtros reutilizados del desarrollo previo.
- `datos.xml`, `css/datos.css`, `xml.html`, `js/xml.js`: XML y visualización.

## Alcance

No registra solicitudes, no autentica usuarios y no almacena datos personales. Los contenidos de los trámites deben verificarse contra sus páginas oficiales antes de su publicación. La presentación ejecutiva no forma parte de esta etapa.
